Merging PDFs is common for applications, invoices, and study packs. Cloud converters work, but they require uploading sensitive documents.

## Merge locally instead

QuickFile Tools uses a browser PDF library so pages are combined on your device.

## Steps

1. Open [PDF Merge](/tools/pdf-merge).
2. Add two or more PDF files.
3. Use **Up** / **Down** to set the order.
4. Click **Merge PDFs** and download `merged.pdf`.

## Troubleshooting

- Encrypted or damaged PDFs may fail — remove protection first if you own the file.
- Very large PDFs can take longer and use more memory in the browser tab.

## Privacy note

Selected PDFs stay in the browser for processing. We do not receive the file contents.
